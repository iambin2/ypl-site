# 최종 검증 (2026-11-02, 브랜치 design-law)

16장의 일곱 항목을 그대로 따릅니다. 수치는 빌드본을 실제 데이터로 띄워 측정했습니다.

## 1. 토큰 밖에 남은 값

| 찾은 것 | 결과 | 남은 이유 |
|---|---|---|
| CSS의 색 리터럴 (tokens.css 밖) | 19개 | 포켓몬 타입 18색(내용), 영상 여백의 검정 1색 |
| JS의 색 리터럴 | 20개 | 팀 시트의 타입 18색, 기록 데이터의 기본값 2개(화면에 그려지지 않음) |

| 간격의 임의 px | 12종 20곳 | 고정 요소를 비키는 거리. `designLaw`의 `EXCEPT`에 이유와 함께 등록 |

**법칙이 아직 덮지 않는 것:** width와 height의 px 값은 39종 204곳입니다. 대부분 4의 배수인 부품 크기(버튼, 스프라이트, 아이콘)이고 `designLaw` 검사 대상이 아닙니다.

전은 Phase 1 인벤토리(법칙 적용 직전)입니다. 괄호는 토큰이 아닌 값의 종류 수입니다.

| 항목 | 전 | 후 |
|---|---|---|
| font-size | 21 (11) | 16 (0) |
| font-weight | 4 | 3 |
| line-height | 11 (11) | 8 (3) |
| letter-spacing | 6 (4) | 7 (0) |
| radius | 18 (5) | 12 (2) |
| z-index | 16 (11) | 11 (0) |
| 지속 시간 | 15 (9) | 8 (0) |
| opacity | 13 (10) | 5 (0과 1만) |
| 브레이크포인트 지점 | 6 | 3 (640, 860, 1100) |
| 간격의 임의 px | 14종 26곳 | 12종 20곳 |

letter-spacing은 종류가 늘었지만 값이 전부 토큰이 되었고, box-shadow는 종류 수가 그대로입니다.

## 6. 13장 재점검

**시각**

| 항목 | 결과 |
|---|---|
| 그라디언트 배경과 글자 | 0건. CSS의 `gradient` 4곳은 단색 구분선 1, 아레나 동심원 1, 가로 스크롤 끝 마스크 2 |
| 블롭, 글래스, blur | 0건 |
| 스크롤 등장 애니메이션 | 0건 (Reveal 제거) |
| 벤토, 가짜 후기, 로고 띠, New 배지, 반짝이 아이콘 | 0건 |
| 프레임워크 기본값, 형광 강조 | 0건 |
| 같은 곡률, 같은 여백 | 곡률 12, 24, pill 세 단. 구역 여백은 내용에 따라 다름 |

남긴 것과 이유:

- **중앙 히어로와 버튼 두 개:** 승인된 결정. 아래는 목업이 아니라 실제 챔피언 슬랩입니다.
- **숫자 롤링:** 승인된 결정. 실제 데이터(59번의 대회, 71명의 트레이너)입니다.
- **소개 페이지의 번호 카드:** 3열과 4열 카드지만 아이콘 없는 실제 순서입니다(참가 3단계, 시즌 4단계).

**문구**

추상 어휘, 재촉, 번역투, 세 형용사 나열, 영문 마케팅 어휘, 느낌표, 엠대시, 가운뎃점, 물결표, 이모지 모두 코드의 화면 문구에서 0건입니다. 공지 제목의 엠대시와 이모지는 사람이 쓴 내용이라 대상이 아닙니다. "모든 승부가 기록이 됩니다"는 실제 일어나는 일이라 유지했습니다.

## 7. 남은 예외

모두 `DESIGN.md` 또는 `designLaw`의 `EXCEPT`에 이유가 적혀 있습니다.

| 예외 | 이유 |
|---|---|
| 포켓몬 타입 18색 | 내용이지 장식이 아님 |
| 영상 여백 `#000` | 두 테마 모두 검정 |
| 첫 방문 라이트 | 시스템 설정 대신 라이트로 열기로 결정(24차) |
| 파비콘이 로고 축소판 | 깃털을 지우면 워글이 사라짐. 칸 안에서 키워 해결 |
| 정지된 `filter: brightness` 1곳 | 전당 포켓몬의 원근. 움직이지 않음 |
| 끝단 마스크 | 가로 스크롤이 이어짐을 알림 |
| hover의 배경색과 글자색 전환 62곳 | 작은 칸 하나의 상태 변화. 이동이 아님 |
| 고정 요소를 비키는 px | 값이 그 요소의 크기 |
| 경기 카드 16px 곡률 | 동심원: 안쪽 12 + 패딩 4 |
| 줄 높이 `1`, `1.25em`, `28px` | 칸 안 라벨, 숫자 롤, 이웃 칸과 맞춤 |
| 마우스 환경의 40px 버튼 | 44px은 터치 기준 |
| 운영자 데이터 오류의 ID, 동기화 같은 용어 | 원인을 찾는 단서 |
| 쓰이지 않는 토큰 19개 | 상태색 14개와 링크, 강조 단계 5개. 법칙의 빈칸으로 유지 |

## 최종 검증에서 찾아 고친 것

- `::selection`이 정의되지 않은 토큰을 가리켜 글자 선택 색이 적용되지 않았습니다. Phase 5 보고의 "선택 색 적용"은 틀렸습니다. 고쳤고 `tokenLaw`로 막았습니다.
- 전당의 `transition: filter`가 움직임 법칙 위반이었습니다. opacity로 바꾸고 `designLaw`에 규칙을 넣었습니다.
- `--sheet-w`를 실제로 연결했습니다. 쓰이지 않던 토큰 6개를 지웠고, `DESIGN.md`의 읽기 폭 720을 실제 값 40em으로 고쳤습니다.
