## 적용 중 달라진 점

- 같은 패턴이 목록보다 더 있어 함께 고쳤습니다: ~하세요 7건, `+` 라벨 2건(선택지 추가, 4강 팀 추가), 브라우저 기본 날짜 표기 2건(팀 빌더).
- `알 수 없는 오류`는 코드에 4곳이 아니라 25곳 있었습니다. 다시 하면 되는 곳은 `잠시 뒤 다시 시도해 주세요.`로, 되돌리기가 함께 실패해 다시 시도가 답이 아닌 곳은 `원인을 확인하지 못했습니다.`로 나눴습니다.
- 팀을 넘기지 못했을 때의 안내는 원인이 브라우저 저장이라 6번의 문장을 썼습니다.
- 포인트 기준 문구는 문장이 끊겨 있어 `4강 20점입니다.`로 마침표를 더했습니다.
- 테스트 2곳이 옛 라벨을 찾고 있어 함께 고쳤습니다 (`bracketApplyRender`, `championsUxRegression`).
