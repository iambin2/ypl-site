# YPL 디자인 법칙 초안 (Phase 2)

승인 전 초안입니다. 승인되면 Phase 3에서 루트의 `DESIGN.md`를 이 법칙으로 교체합니다. 이 문서의 모든 수치는 아래 2.3의 근원에서 파생됩니다.

## 2.1 컨셉 한 문장

**봉인된 공식 기록부: 흰 종이에 네이비 잉크 한 색으로 사실을 굵게 적고, 챔피언만 케이스에 담아 세운다.**

이 사이트의 내용은 실제 대진에서 나온 기록입니다. 그래서 장식이 아니라 기록 자체가 화면을 만듭니다. 한 장의 기록부처럼 조용하고, PSA의 감정 케이스처럼 한 가지 대표 사물만 강하게 세웁니다.

**고유한 특징 하나: 12도 사선.** 글자 로고의 기울기가 곧 사이트의 유일한 장식입니다. 슬랩을 지나는 띠, 로더의 띠, YPL을 지나는 띠가 모두 같은 12도입니다. 다른 장식은 만들지 않습니다.

## 2.2 원칙

| 원칙 | 이유 | 그래서 하지 않는 것 |
|---|---|---|
| **사실이 장식을 대신한다** | 기록이 이 사이트의 존재 이유다 | 일러스트, 의미 없는 배지, 입력한 수치. 화면의 숫자는 모두 데이터에서 읽는다 |
| **위계는 크기와 굵기로 만든다** | 색이 하나뿐이다 | 강조하려고 글자에 색을 칠하지 않는다. 굵은 글자와 큰 글자로만 구분한다 |
| **면은 단색 하나로 나눈다** | 사용자가 고른 PSA식 단색 | 테두리와 그림자와 배경 차이를 겹쳐 쓰지 않는다. 그라디언트도 쓰지 않는다 |
| **움직임은 응답이거나 사건이다** | 스프링은 사이트의 정체성이지만 습관이 되면 AI스럽다 | 섹션마다 떠오르기, 카드마다 호버 떠오르기를 하지 않는다 |
| **대회장의 폰이 기준이다** | 주 사용 장면이다 | 호버에 의존하는 기능, 44px 미만 터치 영역, 작은 글자를 쓰지 않는다 |

허용하는 움직임은 눌림 응답, 선택 렌즈, 시트, 페이지 전환, 홈 첫 등장, 슬랩 띠, 숫자 굴림, 아레나뿐입니다.

## 2.3 수치 체계의 근원

### 기본 단위: 4px

간격, 컴포넌트 높이, 곡률은 4의 배수입니다.

| 간격 | 쓰임 |
|---|---|
| 4 | 제목과 회색 줄, 라벨과 값 |
| 8 | 요소 안, 나란한 컨트롤 |
| 12 | 같은 묶음의 항목, 슬랩 안쪽 |
| 16 | 카드 안 블록, 컨트롤과 그 내용, 폰 바깥 여백 |
| 24 | 카드 안쪽 여백, 페이지 제목과 내용, 데스크톱 격자 간격 |
| 32 | 데스크톱 바깥 여백 |
| 40 / 56 | 섹션 사이 (폰 / 데스크톱) |
| 80 / 120 | 큰 장 사이 (폰 / 데스크톱) |

20은 제거하고 16 또는 24로 옮깁니다. 섹션 간격은 내용 관계에 따라 40과 80 두 단계를 구분해서 씁니다.

### 타입 스케일: 16px 기준, 비율 1.2

16에서 1.2배씩 키우고 4px 격자에 맞춥니다. 24 위로는 한 단계씩 건너뛰어 크기 차이를 분명하게 둡니다. 1.2를 고른 이유는 표와 목록이 많은 폰 화면에서 1.25 이상이면 단계가 너무 벌어지기 때문입니다.

| 스타일 | 크기 | 행간 | 자간 | 굵기 | 쓰임 |
|---|---|---|---|---|---|
| caption | 13 | 1.5 | .01em | 400, 600 | 날짜, 회색 줄, 탭 라벨, 단위 |
| body | 16 | 1.65 | .01em | 400 | 본문, 설명 |
| label | 16 | 1.35 | .01em | 600 | 행 제목, 버튼, 메뉴, 입력창 |
| lead | 20 | 1.45 | -.01em | 600 | 작은 제목, 강조 문장 |
| h3 | 24 | 1.35 | -.015em | 700 | 카드와 시트 제목 |
| h2 | 32 | 1.25 | -.02em | 700 | 섹션 제목, 작은 수치 |
| h1 | 48 | 1.25 | -.02em | 700 | 페이지 제목, 중간 수치 |
| display | 72 | 1.25 | -.025em | 700 | 큰 수치, 홈의 숫자 문장 |
| hero | 96 | 1.25 | -.025em | 700 | 홈의 첫 문장, 챔피언 이름 |

- 크기는 13, 16, 20, 24, 32, 48, 72, 96의 8단계뿐입니다. 큰 제목은 `clamp()`로 줄이되 끝값이 이 단계여야 합니다.
- 굵기는 400, 600, 700의 3종이고 Freesentation 500 파일을 뺍니다.
- 본문 폭은 `40em`까지입니다. 한글 약 40자에 해당합니다.

현재 값은 이렇게 옮깁니다.

| 현재 | 이후 | 영향 |
|---|---|---|
| 12 | 13 | 탭 라벨과 작은 칩이 약간 커짐 |
| 15 | 16 또는 13 | 설명문은 16, 부가 정보는 13. 폰에서 글이 약간 길어짐 |
| 17, 18 | 16 또는 20 | 기사 본문은 16 |
| 28, 36 | 32 | 제목 단계 통합 |

### 형태: 슬랩 규칙

사이트의 대표 사물인 슬랩에서 곡률을 가져옵니다. **바깥 24 = 안쪽 12 + 여백 12.**

| 곡률 | 쓰는 곳 |
|---|---|
| 12 | 안쪽 면, 타일, 여러 줄 입력창, 팝오버 안의 행 |
| 24 | 카드, 슬랩, 시트, 팝오버 |
| 완전한 알약 | 버튼, 한 줄 입력창, 칩, 탭 |
| 0 | 화면 폭을 다 쓰는 면 |

현재 쓰는 36, 32, 20, 18, 16, 8은 없앱니다. 사이트 전체가 지금보다 덜 둥글어 집니다.

### 컨트롤 높이

| 높이 | 쓰임 |
|---|---|
| 24 / 28 | 숫자 배지 / 칩 |
| 40 | 작은 버튼, 시트의 닫기, 탭 트랙 안 |
| 48 | 기본 버튼, 입력창, 드롭다운 |
| 56 | 홈의 주 버튼 |
| 60 | 목록 행 |

44는 터치 영역의 최소값입니다.

### 색: 네이비 하나에서 파생

회색은 네이비의 색조(OKLCH 260도)를 약하게 섞어 계산했습니다. 눈에 보이는 네이비는 바꾸지 않습니다.

| 원시 토큰 | 값 | 비고 |
|---|---|---|
| navy-950 | `#081C3D` | 브랜드 |
| navy-900 / 800 / 700 | `#12284C` `#1D3156` `#2A4170` | 다크의 면, 바 위 렌즈 |
| gray-50 / 100 / 200 | `#F5F7F9` `#EEF0F4` `#E1E5EB` | 면 |
| gray-300 / 400 / 500 | `#CCD1D9` `#A5ABB5` `#79818D` | 다크의 글자 |
| gray-600 / 700 | `#5D646F` `#474D58` | 라이트의 글자 |
| white | `#FFFFFF` | 페이지 바탕. PSA 인상을 만드는 값이라 유지 |

순수 검정은 쓰지 않습니다. 글자도 네이비입니다.

| 의미 토큰 | 라이트 | 다크 | 대비 |
|---|---|---|---|
| text-primary | navy-950 | white | 16.9 / 16.9 |
| text-secondary | gray-700 | gray-300 | 8.5 / 11.0 |
| text-tertiary | gray-600 | gray-400 | 6.0 / 7.3 |
| surface 위 tertiary | gray-600 on gray-100 | gray-400 on navy-900 | 5.2 / 6.3 이상 |

모든 글자 조합이 AA(4.5:1)를 넘습니다. 전체 표는 Phase 3에서 `DESIGN.md`에 남깁니다.

투명도로 만든 색은 불투명 토큰으로 바꿉니다. 예외는 시트 뒤의 딤과 비활성 상태 두 가지입니다.

### 깊이

| 단계 | 의미 | 표현 |
|---|---|---|
| 0 | 페이지의 모든 면 | 그림자 없음, 배경 차이로 구분 |
| 1 | 팝오버, 드롭다운 | 그림자 하나 |
| 2 | 시트, 대화상자 | 그림자 하나, 더 깊게 |

그림자는 위에서 내려오는 한 방향이고 네이비 기반입니다. z-index는 이름 있는 스케일로만 씁니다.

`base 0 / raised 1 / sticky 10 / header 20 / overlay 30 / modal 40 / popover 50 / toast 60 / tooltip 70 / skip 80`

### 모션

| 토큰 | 값 | 쓰임 |
|---|---|---|
| instant | 90ms | 눌림 시작 |
| fast | 180ms | 색 변화, 퇴장 |
| base | 260ms | 페이드 |
| slow | 480ms | 등장 |
| spring-snappy / soft | 400 / 670ms | 움직이는 것, 떠오르는 층 |
| sweep | 900ms | 12도 띠 |

곡선은 등장용 ease-out, 퇴장용 ease-in, 이동용 ease-in-out과 스프링 둘입니다. 성격은 **빠르고 단정하되 끝에서 살짝 탄력**이 있습니다. 움직이는 속성은 transform과 opacity뿐입니다.

### 레이아웃

| 항목 | 값 |
|---|---|
| 브레이크포인트 | 640, 860, 1100 |
| 격자 | 데스크톱 4열 간격 24, 폰 2열 간격 16 |
| 바깥 여백 | 폰 16, 데스크톱 32 |
| 콘텐츠 폭 | 전체 1200, 읽기 720, 시트 560 |

현재의 760, 1024, 1280 분기는 이 셋으로 합칩니다.

## 2.4 대안

| 방향 | 내용 | 평가 |
|---|---|---|
| **A. 봉인된 공식 기록부 (추천)** | 위 내용 | 지금까지 확정한 PSA 방향, 단색, 굵은 글자를 그대로 잇고 기록이라는 제품의 본질을 드러냅니다 |
| B. 경기 전광판 | 네이비 바탕을 기본으로, 고정폭 숫자가 격자에 맞춰 큰 면을 차지 | 대회 당일에는 강렬하지만, 공지와 기록을 읽는 평소 화면이 무거워지고 라이트 기본 결정을 뒤집습니다 |
| C. 인쇄된 대진표 | 세리프 제목, 가는 괘선, 흰 종이의 편집 디자인 | 품격은 있지만 괘선이 많아져 폰 화면이 복잡해지고, 경쾌한 스프링 움직임과 어긋납니다 |

## 확인이 필요한 항목

1. **상태색:** 지시문 3.1은 성공, 경고, 위험, 정보 색을 요구합니다. 사이트에는 지금 상태색이 없고 "완전한 단색"이 사용자 선호입니다. **추천:** 네 토큰은 정의하되 값을 네이비와 회색으로 두고, 상태는 글자와 아이콘, 굵기로 전달합니다. 색만으로 전달하지 않으므로 접근성도 충족합니다.
2. **작은 글자:** 12px과 15px을 없애면 표가 많은 화면에서 글이 약간 길어집니다. 폰에서 깨지는 곳은 구현 중에 찾아 고칩니다.
