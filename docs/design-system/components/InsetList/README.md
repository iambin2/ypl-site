# InsetList

이어지는 행을 `bg-2` 연속 곡률 면 하나에 담는 목록. 랭킹, 공지, 게시글, 기록 표가 모두 이 모양이다.

## 쓰는 법
- 소비자가 주는 것: 행들(제목, 선택적 메타 줄, 끝의 값이나 날짜), 순위 목록이면 순위.
- 행 최소 56px, 면 안쪽 좌우 16px.
- 행 사이는 0.5px `line` 구분선. 글자가 시작하는 지점부터, 순위 목록이면 순위 숫자 뒤에서 시작해 둥근 가장자리에 닿지 않는다.
- 순위와 점수는 `figure` 숫자, 단위는 `unit`. 점수 열은 오른쪽 정렬.
- 1위를 따로 강조해야 하면 순위 숫자를 `ink` 반전 원으로. 색은 쓰지 않는다.

## 하지 않는 것
- 면 밖의 전폭 구분선, 첫 행 위와 마지막 행 아래의 선.
- 면 안에 또 다른 카드.
