# PartyPod

우승 파티의 포켓몬 한 마리를 세우는 받침 칸. 파티는 언제나 여섯 칸.

## 쓰는 법
- 소비자가 주는 것: 포켓몬 이미지(공식 아트워크, 투명 배경)와 이름(대체 텍스트).
- 칸은 `pod-face` 면, `radius-md`, 높이 124(데스크톱 132). 발밑에 `pod-floor` 타원(다크는 빛, 라이트는 그림자).
- 이미지는 80px(데스크톱 82px) 정사각 안에 `contain`, 가운데.
- 폰 3열 두 줄, 데스크톱 6열 한 줄. 간격 8.
- 슬롯 순서 그대로, 빈 칸은 같은 크기의 빈 받침으로.

## 하지 않는 것
- 거울 반사, 테두리, 드롭 그림자, 흑백 처리, 이미지 자르기.
