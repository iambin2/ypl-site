# Segmented

같은 내용의 여러 보기 사이를 바꾸는 유리 캡슐 트랙과, 그 아래의 보조 필터.

## 쓰는 법
- 소비자가 주는 것: 2~5개의 보기 이름, 현재 보기.
- 트랙은 유리 면(반경 22), 안쪽 여백 4. 선택 칸은 주 버튼 면에 `on-primary` 글자 900, `shadow-thumb`, 반경 18(동심). 경쾌 스프링으로 미끄러지고 도중에 방향을 바꿀 수 있다.
- 보조 필터(`ypl-pill`)는 시즌이나 리그처럼 한 단계 아래의 고르기. 34px 캡슐, 쉬는 상태 `fill-2`, 고른 것 `fill`과 `ink`.
- 페이지 이동이 아니라 같은 화면 안의 보기 전환에만 쓴다.

## 하지 않는 것
- 밑줄 탭, 실버 선택 칸, 색칠한 선택 칸.
