# ExploreCard

홈의 "리그 둘러보기" 기능 카드. 여섯 장이 모두 같은 모양이다.

## 쓰는 법
- 소비자가 주는 것: 라틴 머리말(LIVE, RECORDS, HALL OF FAME, TITLES, TOOL, NEWS), 제목, 설명 한 줄, 이동할 곳.
- 유리 면, `radius-lg`, 폰 최소 132px(안쪽 18 16 16), 데스크톱 176px(26 26 22).
- 제목 `card-title`(19, 데스크톱 24) 900, 설명 `callout`(13~15) `text-2`, 오른쪽 아래 화살표 원(28, 데스크톱 32).
- 진행 중인 것이 있으면 LIVE 앞에 맥박 점.
- 폰 2열, 640 이상 3열. 호버에서 2px 들리고 윗면이 밝아지며 화살표가 2px 밀린다.

## 하지 않는 것
- 카드마다 다른 크기나 배치, 아이콘 일러스트, 실버 제목.
- 커서 빛. 커서 빛은 히어로와 피처 카드만.
