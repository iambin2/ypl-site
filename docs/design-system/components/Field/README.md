# Field

라벨, 입력창, 힌트 또는 오류를 한 묶음으로 세운다.

## 쓰는 법
- 소비자가 주는 것: 라벨, 자리표시 글자, 힌트, 오류 문장, 필수 여부.
- 입력창은 48px, `fill-2` 바탕, `radius-sm` 연속 곡률, 글자 16px(iOS 확대 방지).
- 포커스: 바탕 `bg`, 테두리 `ink`, 4px 바깥 후광(`fill`).
- 오류는 필드 바로 아래, `danger` 글자와 alert 아이콘, 고치는 방법을 한 문장으로.

## 하지 않는 것
- 라벨 없이 자리표시 글자만 두기. 외곽선 상자 입력창.
