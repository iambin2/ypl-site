# Chip

상태와 분류를 짧게 붙이는 28px 캡슐. 기본(`fill`), 반전(`ink`), 리드 타일 위(`lead-fill`) 세 가지.

## 쓰는 법
- 소비자가 주는 것: 짧은 글자, 진행 중이면 맥박 점, 상태색이 필요하면 아이콘과 함께.
- 맥박 점은 지금 열려 있는 것(접수 중, 제출 중, 경기 중)에만. 사이트의 유일한 무한 반복.
- 상태색(`ok`, `warn`, `danger`)은 글자와 아이콘에만 쓰고 칩 바탕은 언제나 `fill`.
- 반전 칩은 하나뿐인 것(현 챔피언)에만.

## 하지 않는 것
- 색을 칠한 바탕, 외곽선 칩, 이모지.
