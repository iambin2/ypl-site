# NowBar

지금 진행 중인 대회의 단계와 마감을 한 줄로 알리는 유리 띠. 히어로 바로 아래에 선다.

## 쓰는 법
- 소비자가 주는 것: 대회명과 현재 단계(신청 중, 파티 제출 중, 대진 공개, 경기 중), 마감 또는 일시, 이동할 곳.
- 왼쪽에 맥박 점(`live`), 라틴 머리말 NOW, 한 문장. 오른쪽에 마감과 화살표 원(데스크톱).
- 띠 전체가 하나의 링크다. 호버에서 유리 카드처럼 들린다.
- 진행 중인 대회가 없으면 그리지 않는다. 빈 띠를 남기지 않는다.

## 하지 않는 것
- 띠를 두 개 이상 쌓기, 단계 진행 막대, 빨간 바탕.
