# TypeBadge

포켓몬 타입을 붙이는 24px 캡슐. 팀 빌더의 포켓몬 목록과 편집기 머리에 쓴다.

## 쓰는 법
- 바탕은 언제나 `fill`, 글자 `ink`, `caption` 12/600.
- 타입 색은 글자 앞 8px 점에만 쓴다. 타입은 게임 안에서 뜻을 갖는 색이므로 무채색 규칙의 예외인 "의미 있는 색"에 든다. [Chip](../Chip/README.md)과 같은 법: 색은 바탕이 아니라 표식에만.
- 두 타입은 4px 간격으로 나란히. 줄이 모자라면 다음 줄로 넘긴다(말줄임 없음).

## 하지 않는 것
- 타입 색으로 칠한 바탕, 흰 글자, 외곽선, 아이콘 이미지.
