# AdminStrip

관리자 모드가 켜져 있음을 알리는 띠. 내비게이션 바로 아래 전체 폭에 붙는다.

## 쓰는 법
- 높이 36px, `bg-2` 면, `footnote` 13px. 왼쪽에 7px `ink` 점, `label`(600) "관리자 모드", 이어서 `text-3`의 한 문장 설명.
- 폰에서는 설명을 숨기고 점과 "관리자 모드"만 남긴다.
- 화면의 반전 면은 리드 타일 하나뿐이므로 띠는 반전하지 않는다. 모드는 언제나 보이되 다음 행동과 경쟁하지 않는다.
- 편집기 안의 동그란 도구 버튼(이동, 삭제, 비우기)은 32px 원, `fill-2`. 삭제 도구는 호버에서만 `danger` 글자.
- 편집기의 묶음(질문, 라운드, 순위 행)은 `bg-2` 면에 담고, 그 안의 입력창은 한 단계 위 `bg`(다크 `bg-3`)로 띄운다.

## 하지 않는 것
- 노란 경고 띠, 줄무늬, 맥박 점(맥박은 접수 중인 대회 전용).
- 편집기 묶음의 외곽선 상자, 점선 "추가" 상자.
