# Dialog

태블릿과 데스크톱의 가운데 대화상자. 폰에서는 같은 내용이 Sheet로 바뀐다.

## 쓰는 법
- 소비자가 주는 것: 제목, 한 문장 설명(선택), 내용, 행동 줄(선택).
- 폭 580(넓은 표는 780), `surface` 면, `shadow-float`, `radius-xl`. 안쪽 여백 32.
- 제목 24/900, 설명 14 `text-2`. 주된 행동이 오른쪽.
- 중앙에서 0.96배로 자라며 기본 스프링으로 열리고, `duration-exit`로 닫힌다.
- Esc와 배경 누르기로 닫힌다. 배경 어둡게는 겹치지 않는다.

## 하지 않는 것
- 브라우저 기본 alert, confirm, prompt. 창 외곽선, 제목 아래 구분선. 유리 면 대화상자(떠 있는 층은 `surface`).
