# Dialog

태블릿과 데스크톱의 가운데 대화상자. 폰에서는 같은 내용이 [Sheet](../Sheet/README.md)로 바뀐다. 사이트의 확인, 짧은 입력, 관리자 편집기, 대진표 마법사가 모두 이 창 하나를 쓴다.

## 쓰는 법
- 소비자가 주는 것: 제목, 한 문장 설명(선택), 내용, 행동 줄(선택).
- 폭 580px(팀전 경기처럼 표가 넓으면 780px), `surface` 면, `shadow-float`, `radius-xl` 연속 곡률. 안쪽 여백 `space-7`.
- 제목 `title-3`(24/800), 설명 `callout`, `text-3`. 제목 오른쪽 위에 36px 원형 닫기 버튼(`fill-2`).
- 행동 줄은 창 아래에 붙어 내용이 길어도 보인다. 구분선 없이 `surface` 면으로만 덮는다. 주된 행동이 오른쪽.
- 행동 줄이 없는 창도 아래 여백 `space-7`로 끝난다.
- 안에 놓이는 면은 한 단계 위(`bg-2`)이고, 반경은 창보다 작다(`radius-lg`).
- 중앙에서 0.96배로 자라며 기본 스프링으로 열리고, 0.7배 빠르게(`duration-exit`) 튕김 없이 닫힌다. 배경 어둡게는 150ms.
- Esc와 배경 누르기로 닫힌다. 창 위에 창이 열리면 Esc는 맨 위 창만 닫고, 배경 어둡게는 겹치지 않는다.

## 하지 않는 것
- 브라우저 기본 alert, confirm, prompt.
- 행동 줄 위의 괘선, 창 외곽선, 제목 아래 구분선.
