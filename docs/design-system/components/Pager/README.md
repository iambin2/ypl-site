# Pager

긴 목록을 쪽으로 나눌 때 목록 바로 아래 가운데에 선다.

## 쓰는 법
- 소비자가 주는 것: 현재 쪽, 전체 쪽 수.
- 버튼은 44px 캡슐, `control` 15/600, 고정폭 숫자. 현재 쪽만 `ink` 반전.
- 현재 쪽 양옆 두 쪽씩 보이고, 멀리 있는 처음과 끝은 말줄임표 뒤에 둔다.
- 이전, 다음은 화살표 아이콘과 화면 낭독기 라벨. 끝에서는 흐린 상태(`opacity-disabled`).
- 목록과의 간격은 `space-6`. 한 쪽뿐이면 그리지 않는다.

## 하지 않는 것
- 쪽 번호에 외곽선 원, 밑줄로 현재 쪽 표시.
