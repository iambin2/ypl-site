# LeadTile

홈 첫 화면의 주인공. 지금 대회 단계에서 회원이 할 일 하나를 보여준다. 화면에 하나뿐인 반전 면이다.

## 쓰는 법
- 소비자가 주는 것: 대회명, 현재 단계(공고, 신청, 제출, 대진, 결과), 포스터 숫자(D-day), 사실 세 줄(일시, 방식, 정원), 다음 행동과 마감, 버튼 하나.
- 단계에 따라 버튼이 바뀐다: 신청 중이면 "참가 신청하기", 제출 중이면 "파티 제출하기", 대진 공개 뒤면 "대진표 보기", 끝나면 "결과 보기".
- 진행 중인 대회가 없으면 최근 대회 결과를 같은 자리에 같은 모양으로 둔다. 포스터 숫자는 결과 날짜.
- 안에 면을 더 넣을 때는 동심 규칙: 28 − 20 = 8.

## 하지 않는 것
- 한 화면에 리드 타일 둘.
- 포켓몬 파티 그림을 넣기. 그건 명예의 전당의 자리.
