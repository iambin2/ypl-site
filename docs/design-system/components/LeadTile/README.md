# LeadTile

홈 첫 화면의 주인공. 지금 대회 단계에서 회원이 할 일 하나를 보여준다. 화면에 하나뿐인 반전 면이다.

## 쓰는 법
- 소비자가 주는 것: 대회명, 현재 단계(공고, 신청, 제출, 대진, 결과), 포스터 숫자(D-day), 사실 세 줄(일시, 방식, 정원), 다음 행동과 마감, 버튼 하나.
- 단계에 따라 버튼이 바뀐다: 신청 중이면 "참가 신청하기", 제출 중이면 "파티 제출하기", 대진 공개 뒤면 "대진표 보기", 끝나면 "결과 보기".
- 진행 중인 대회가 없으면 최근 대회 결과를 같은 자리에 같은 모양으로 둔다. 포스터 숫자는 결과 날짜.
- 안에 면을 더 넣을 때는 동심 규칙: 28 − 20 = 8.

## 깊은 페이지의 리드 타일
홈이 아닌 페이지도 같은 리드 타일로 시작한다. 칩, 제목, 포스터 숫자, 사실 목록이 같은 자리에 같은 크기로 선다.
- 기록: 트레이너의 우승 횟수, 포켓몬의 등록 엔트리 수, 랭킹 1위의 점수.
- 명예의 전당: 현 챔피언, 포스터 숫자는 몇 대 챔피언인지. 데스크톱에서는 우승 엔트리 그림이 타일 오른쪽 절반에 선다.
- 칭호: 고른 분류, 포스터 숫자는 달성 수(예: 5 / 5).
- 대진표 목록: 가장 최근 대진표, 포스터 숫자는 참가 수. 끝난 대진표는 우승자가 판 위의 리드 타일이 된다.
- 리드 위 보조 버튼은 `lead-tonal`, 주된 버튼은 `on-lead`.

## 하지 않는 것
- 한 화면에 리드 타일 둘.
- 포켓몬 파티 그림을 넣기. 그건 명예의 전당의 자리.
