# ResultRow

끝난 대회 하나를 회차, 리그, 우승자로 요약하는 유리 목록의 행.

## 쓰는 법
- 소비자가 주는 것: 회차, 리그 이름, 연월과 규칙(메타), 우승자, 준우승자.
- 왼쪽 회차는 `figure`(22, 데스크톱 26) 실버와 단위 "회"(11px), 폭 44(데스크톱 54) 고정.
- 가운데 리그 이름 `headline` 700, 아래 메타 "2026년 7월 랜덤파트너".
- 오른쪽 우승자 900, 아래 메타 "준우승 이상준".
- 홈에는 최근 세 줄, 기록 페이지에는 회차 전체.

## 하지 않는 것
- 행마다 리그 색, 우승자 옆 트로피 아이콘, 날짜만 있고 회차 없는 행.
