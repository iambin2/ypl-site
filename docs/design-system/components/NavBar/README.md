# NavBar

모든 화면 맨 위에 붙는 56px 내비게이션. 로고, 페이지 링크, 테마와 관리자와 디스코드가 한 줄에 선다.

## 쓰는 법
- 소비자가 주는 것: 현재 페이지, 링크 목록(소개, 공지, 게시판, 기록, 대진표, 칭호, 명예의 전당, 도구), 테마 상태, 관리자 상태.
- 바탕은 `bg`의 78% 반투명에 `saturate(180%) blur(20px)`. 흐림은 `::before`에 건다. 그래야 그 안의 전체 메뉴가 화면 기준으로 열린다(07 깊이).
- 링크는 로고 바로 뒤, 하나의 왼쪽 축에 선다. `control` 15/600, 쉬는 상태 `text-2`.
- 현재 페이지는 `fill` 캡슐 면과 `ink` 글자. 밑줄은 쓰지 않는다(09 상태).
- 테마와 관리자는 44px 원형 아이콘 버튼, 디스코드는 36px 기본 캡슐.
- "도구"는 280px 메뉴를 연다. `surface`, `shadow-pop`, `radius-lg`, 누른 버튼 모서리에서 0.9배로 자라고(기본 스프링) 0.7배 빠르게 닫힌다. 안의 항목 반경은 동심 계산 20 − 8 = 12.
- 1024px 미만에서는 링크, 관리자, 디스코드가 빠지고 버거가 들어온다. 버거는 같은 굵기(2px) 두 줄이고 경쾌 스프링으로 X가 된다.

## 하지 않는 것
- 내비게이션 아래 구분선. 반투명 바탕이 경계다(06 선과 면의 다섯 가지 선에 없다).
- 현재 위치를 밑줄이나 굵기만으로 표시하기.
- 로고에 호버 확대.
