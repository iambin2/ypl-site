# NavBar

모든 화면 맨 위에 붙는 헤더. 폰 60px, 데스크톱 72px.

## 쓰는 법
- 소비자가 주는 것: 현재 페이지, 링크 목록(홈, 공지, 대진표, 기록, 칭호, 명예의 전당, 팀 빌더, 소개), 테마 상태.
- 왼쪽: 실버로 채운 워글 마크(마스크, 40×24, 데스크톱 46×27)와 실버 "YPL" 워드마크(`latin` 800).
- 바탕은 `bg`의 72% 반투명에 `saturate(180%) blur(20px)`, 흐림은 `::before`에. 아래 구분선은 없다.
- 데스크톱: 링크는 가운데, 14px 500 `text-2`. 현재 페이지는 `fill` 캡슐에 `ink` 700. 오른쪽에 테마 아이콘 버튼.
- 폰: 링크 대신 테마 버튼과 메뉴 버튼(44px 원, 같은 굵기 두 줄). 메뉴 버튼은 경쾌 스프링으로 X가 된다.

## 하지 않는 것
- 헤더 아래 구분선, 밑줄로 현재 위치 표시, 로고 호버 확대.
