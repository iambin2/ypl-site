# PokemonSlot

팀 빌더 파티의 한 칸. 6칸이 폰 2열, 데스크톱 3열 격자로 놓인다.

## 쓰는 법
- 칸은 유리 패널 안의 `fill-2` 면, `radius-md`, 간격 8.
- 채워진 칸: 56px 스프라이트, 이름 15/700, 아래 줄 `meta`(도구, 기술 수). 왼쪽 위에 `latin` 11px 순번.
- 고른 칸은 `glass-hover` 면으로 떠오르고 `shadow-thumb`을 받는다.
- 빈 칸은 가운데에 순번만, `opacity-dim`.
- 지금 규칙에서 확인할 수 없는 포켓몬은 아래 줄 글자를 `warn`으로.

## 하지 않는 것
- 칸 사이 괘선, 고른 칸의 외곽선, 빈 칸의 점선 상자.
