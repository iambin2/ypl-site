# PokemonSlot

팀 구성의 한 칸. 6칸이 데스크톱 3열, 폰 2열 격자로 놓인다.

## 쓰는 법
- 칸은 패널(`bg-2`) 안에서 `fill-2` 면, 반경은 패널과 동심(`radius-xl` − 12). 칸 사이 `space-2`.
- 채워진 칸: 56px 스프라이트, 이름 `callout` 15/600, 아래 줄 `footnote`(도구, 기술 수). 왼쪽 위에 `num` 17px 순번.
- 고른 칸은 세그먼트 선택 칸처럼 `bg`로 떠오르고 `shadow-thumb`을 받는다. 외곽선으로 표시하지 않는다.
- 빈 칸은 가운데에 `num` 32px 순번만, `text-3`를 흐리게(`opacity-dim`).
- 지금 규칙에서 확인할 수 없는 포켓몬은 아래 줄 글자를 `warn`으로.
- 지우기는 오른쪽 위 24px 원. 호버가 있는 기기에서는 칸에 올렸을 때와 고른 칸에서만 보인다.
- 팀 수는 패널 머리 오른쪽에 `figure`(40, 폰 32)와 단위 "/ 6", 줄바꿈 없이.

## 하지 않는 것
- 칸 사이 괘선, 고른 칸의 잉크 외곽선, 빈 칸의 점선 상자.
