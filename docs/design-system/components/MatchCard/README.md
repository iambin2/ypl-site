# MatchCard

대진표의 경기 하나. 정확히 98px, 49px 칸 두 개다. 연결선 위치가 이 높이로 계산되므로 바꾸지 않는다.

## 쓰는 법
- 소비자가 주는 것: 두 선수(또는 미정), 승자, 선택적 시드 번호.
- 판은 유리 면(`radius-xl`), 안쪽 24. 폰에서는 화면 끝까지 펼친다. 판 안에서만 가로로 스크롤된다.
- 경기 카드는 판 위의 `fill-2`, `radius-md`. 두 칸 사이는 좌우 12px 들여 쓴 구분선.
- 승자 칸은 주 버튼 면에 `on-primary` 900. 실버나 왕관으로 표시하지 않는다.
- 아직 정해지지 않은 경기는 `opacity-dim`.
- 연결선은 1.5px `line`, 둥근 끝, 꺾이는 곳 8px. 우승 노드로 가는 마지막 선만 `ink`.
- 우승 노드: 같은 98px, 유리 면, 위에 "우승"(12/700 `text-3`), 아래 이름(22/900 실버).

## 하지 않는 것
- 높이 변경, 칸 사이 굵은 선, 승자 칸 실버 칠, 트로피 아이콘.
