# MatchCard

대진표의 경기 하나. 정확히 98px, 49px 칸 두 개다. 대진표의 연결선 위치가 이 높이로 계산되므로 바꾸지 않는다.

## 쓰는 법
- 소비자가 주는 것: 두 선수(또는 미정), 승자, 선택적 시드 번호.
- 승자 칸은 `ink` 반전에 800. 색이나 왕관 아이콘으로 표시하지 않는다.
- 아직 정해지지 않은 경기는 `opacity-dim`.
- 연결선은 1.5px `line`, 둥근 끝, 꺾이는 곳 8px 둥글게. 우승자로 가는 마지막 선만 `ink`.

## 하지 않는 것
- 높이 변경, 칸 사이 굵은 선, 그림자.

## 대진표 판과 연결선 (3단계)
- 판은 `bg-2` 연속 곡률 면(`radius-xl`), 안쪽 24px. 폰에서는 화면 끝까지 펼치고 모서리를 없앤다.
- 경기 카드는 판 위의 `bg`(다크는 `bg-3`), `radius-md`, 외곽선과 그림자 없음. 두 칸 사이는 좌우 12px 들여 쓴 `hair` 구분선.
- 시드 번호는 `num` 15px, `text-3`. 승자 칸 안에서는 `on-ink` 55%.
- 연결선은 `stroke-connector`(1.5px) `line`, 꺾이는 곳 8px. 우승 노드로 들어가는 마지막 선만 `ink`.

## 우승 노드
- 경기 카드와 같은 98px, 같은 반경. `ink` 반전, 위에 "우승"(13px 600, 70%), 아래 이름(20px 800).
- 왕관이나 트로피 아이콘은 쓰지 않는다. 반전이 곧 표시다.
- 등장은 `y-pop`, 부드러운 스프링 `duration-gentle`.

## 끝난 대진표
- 우승자는 판 위의 리드 타일로 선다: 칩 "우승", 이름, 포스터 숫자는 참가 수, 사실은 준우승, 4강, 날짜. 이미지 저장과 기록 반영 버튼은 리드 위 버튼(`lead-tonal`, `on-lead`).
