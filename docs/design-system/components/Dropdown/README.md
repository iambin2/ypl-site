# Dropdown

목록에서 하나를 고르는 48px 필드. 누르면 아래로 메뉴가 떠오른다.

## 쓰는 법
- 소비자가 주는 것: 선택지(값, 이름), 현재 값, 자리표시 글자, 화면 낭독기 라벨.
- 필드는 Field의 입력창과 같다. 펼침 화살표는 경쾌 스프링으로 뒤집힌다.
- 메뉴는 `surface`, `shadow-pop`, `radius-md`, 안쪽 여백 4px. 항목 반경은 동심 계산(18 − 4 = 14), 높이 44px.
- 선택된 항목은 굵기 700과 체크 표시. 색은 쓰지 않는다.

## 하지 않는 것
- 메뉴의 테두리선, 브라우저 기본 `select` 모양 그대로 두기.
