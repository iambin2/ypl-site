# Dropdown

목록에서 하나를 고르는 48px 필드. 누르면 아래로 메뉴가 떠오른다. 사이트 코드에서는 `Dropdown` 컴포넌트(`.dd`)다.

## 쓰는 법
- 소비자가 주는 것: 선택지(값, 이름), 현재 값, 자리표시 글자, 화면 낭독기 라벨.
- 필드는 Field의 입력창과 같다. 48px, `fill-2`, `radius-sm` 연속 곡률, 글자 16px 400. 열리면 바탕 `bg`, 테두리 `ink`, 4px 후광.
- 메뉴는 `surface`, `shadow-pop`, `radius-md`, 안쪽 여백 4px. 항목 반경은 동심 계산(메뉴 반경 − 4). 항목 높이 44px.
- 경쾌 스프링으로 떠오르고 퇴장값으로 닫힌다. 펼침 화살표는 같은 스프링으로 뒤집힌다.
- 선택된 항목은 굵기 600과 체크 표시. 색은 쓰지 않는다.
- 리드 타일 위에서는 `dd--lead`: 바탕 `lead-fill`, 글자 `on-lead`.

## 하지 않는 것
- 외곽선 상자 필드, 메뉴의 테두리선.
- 브라우저 기본 `select` 모양 그대로 두기.
