# Sheet

폰에서 짧은 입력과 확인을 받는 하단 시트. 태블릿 이상에서는 Dialog로 바뀐다.

## 쓰는 법
- 소비자가 주는 것: 제목, 한 문장 설명, 내용, 행동 버튼 둘.
- 기기 가장자리에서 8px 띄우고 `radius-2xl`(38). `surface` 면, `shadow-float`.
- 여유 스프링으로 올라오고 `duration-exit-gentle`로 내려간다. 배경 어둡게는 150ms.
- Esc, 배경 누르기, 아래로 끌기로 닫힌다. 닫히면 포커스는 연 버튼으로.

## 하지 않는 것
- 시트 위에 시트, 배경 어둡게 두 겹.
