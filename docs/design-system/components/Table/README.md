# Table

열을 비교해야 하는 순위표. InsetList와 같은 `bg-2` 면에 담고, 행은 표의 행이다. 사이트 코드에서는 `StandTable`(`.ypl-table`)이다.

## 쓰는 법
- 소비자가 주는 것: 행(순위, 이름, 우승, 준우승, 4강, 포인트, 선택적 비고).
- 머리 줄은 `label` 13/600 `text-3`, 행 최소 56px, 면 안쪽 좌우 16px.
- 순위와 포인트는 `figure` 숫자(폰 32, 데스크톱 40), 포인트 뒤에 `unit` "점". 숫자 열은 오른쪽 정렬, 고정폭.
- 행 사이 0.5px `line` 구분선은 순위 열 뒤에서 시작해 오른쪽 둥근 가장자리 16px 앞에서 멈춘다.
- 640px 미만에서는 우승, 준우승, 4강 열을 접고 이름 아래 한 줄로 요약한다: "우승 3, 준우승 5, 4강 0".
- 1위 강조는 표 위의 리드 타일이 맡는다. 표 안의 행은 모두 같은 모양이다.

## 하지 않는 것
- 세로 괘선, 머리 줄 아래의 굵은 선, 줄무늬 행.
- 폰에서 가로 스크롤로 열을 밀어내기.
