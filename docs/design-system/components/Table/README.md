# Table

랭킹. 1위는 피처 카드, 2~3위는 나란한 순위 카드, 4위부터는 유리 목록의 행이다.

## 쓰는 법
- 소비자가 주는 것: 행(순위, 이름, 우승, 준우승, 4강, 포인트).
- 1위: FeatureCard(머리말 RANK 1, 이름, `score` 점수, 성적 칸 셋).
- 2~3위(`ypl-rankcard`): 2열, 유리 면 `radius-lg`, 실버 순위 `figure`, 이름 19/900, 점수 `stat`과 단위 "점".
- 4위부터: 유리 목록. 순위 `latin` 700 17px `text-2`(폭 28), 이름과 메타 "우승 1 준우승 0 4강 5", 끝에 점수 `latin` 700.
- 동점은 같은 순위, 다음 순위를 건너뛴다(6, 6, 8).
- 데스크톱에서는 4위 행에 우승, 준우승, 4강을 열로 펼친다. 폰에서는 메타 한 줄로 접는다.
- 사람 수가 많으면 "29명 전체 보기" 유리 버튼으로 펼친다.

## 하지 않는 것
- 세로 괘선, 줄무늬 행, 1~3위 금은동 색.
