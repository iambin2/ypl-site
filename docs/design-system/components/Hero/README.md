# Hero

홈 첫 화면. 세 줄 문구, 소개 한 줄, 버튼 둘. 그 밖에는 아무것도 두지 않는다.

## 쓰는 법
- 소비자가 주는 것: 문구 세 줄, 소개 문장, 주 행동(대회 단계에 따라: 이번 대회 신청하기, 파티 제출하기, 대진표 보기), 보조 행동(리그 소개).
- 라틴 머리말 YONSEI POKÉMON LEAGUE, 문구는 `hero`(46, 데스크톱 104) 900. 앞 두 줄 `ink`, 마지막 줄 실버.
- 소개는 `body` `text-2`, 데스크톱 18px에 최대 640px.
- 데스크톱에서 히어로는 커서 빛을 받는다(`ypl-follow`): 마지막 줄의 실버가 커서를 따라 흐르고 뒤의 옅은 빛이 따라온다. 08 모션의 커서 빛.
- 데스크톱의 오른쪽 빈 자리는 페이지 광원이 채운다.

## 하지 않는 것
- 큰 로고 엠블럼, 파티 그림, 일러스트로 첫 화면을 채우기.
- 네 줄 이상의 문구, 감상적인 구호.
