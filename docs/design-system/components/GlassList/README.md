# GlassList

이어지는 행을 유리 면 하나에 담는 목록. 결과, 랭킹, 공지, 게시글이 모두 이 모양이다.

## 쓰는 법
- 소비자가 주는 것: 행들(앞의 숫자나 아이콘, 이름과 메타 줄, 끝의 값).
- 유리 면, `radius-lg`, 위아래 여백 6(데스크톱 8). 행 최소 56, 안쪽 14 18(데스크톱 18 24).
- 행 사이 구분선은 `line` 0.5~1px, 좌우 18(데스크톱 24) 안에서 끝난다.
- 이름 `headline` 700, 메타 `meta` `text-3`. 끝의 값은 오른쪽 정렬.
- 호버에서 행 바탕이 `fill-2`로 밝아진다. 행은 들리지 않는다.

## 하지 않는 것
- 면 밖의 전폭 구분선, 첫 행 위와 마지막 행 아래의 선, 면 안의 카드.
