# PageHead

모든 페이지의 머리와 모든 섹션의 머리. 라틴 머리말, 두 톤 제목, 설명 한 줄 또는 오른쪽 링크.

## 쓰는 법
- 페이지 머리(`ypl-head`): 머리말, `page-title`(40, 데스크톱 64) 900, 설명 한 줄 `body` `text-2`. 홈만 이 자리에 Hero를 둔다.
- 섹션 머리(`ypl-sec-head`): 머리말, `section-title`(28, 데스크톱 40) 900, 오른쪽 아래에 `link`(13/700 `text-2`, 끝에 →).
- 제목은 두 낱말: 평범한 낱말(`ink`) 뒤에 실버 낱말 하나. "리그 기록", "현재 챔피언", "최근 결과".
- 머리는 카드보다 4px 안쪽에서 시작해 카드 안 글자와 축을 맞춘다.

## 하지 않는 것
- 제목 아래 괘선, 제목 전체를 실버로, 실버 낱말 둘.
- 머리말 없이 제목만, 또는 제목 없이 머리말만.
