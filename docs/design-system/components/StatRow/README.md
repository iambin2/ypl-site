# StatRow

능력 포인트 한 줄. 여섯 줄이 패널 위 한 단계 높은 인셋 그룹(`bg`, 다크 `bg-3`)에 담긴다.

## 쓰는 법
- 행 높이 56px(`row-min`). 열은 이름(110px, 폰 76px), 슬라이더, 숫자 입력(64px, 폰 56px), 최종값(56px, 폰에서는 숨김).
- 이름 `callout` 15/600, 아래에 `footnote`로 종족값.
- 최종값은 `num` 24px. 위에 `caption` "최종".
- 성격 보정은 이름 뒤 ↑ ↓ 글자로만 표시한다.
- 행 사이는 0.5px 인셋 구분선, 그룹의 곡선 가장자리에는 닿지 않는다.
- 총합이 한도를 넘으면 머리의 합계만 `danger`.

## 하지 않는 것
- 행마다 색 막대, 행 아래 굵은 괘선, 보정 능력치를 색으로 칠하기.
