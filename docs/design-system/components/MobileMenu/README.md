# MobileMenu

1024px 미만에서 메뉴 버튼을 누르면 헤더 아래 화면 전체를 덮는 큰 글자 목록.

## 쓰는 법
- 소비자가 주는 것: 현재 페이지, 페이지 목록, 도구 목록, 아래쪽 행동 둘(디스코드 참여, 관리자 로그인).
- 항목은 28px 900(`section-title` 폰 크기), 높이 52. 현재 페이지는 `fill` 캡슐 면, 캡슐은 글자보다 12px 바깥으로 나가 글자가 왼쪽 축을 지킨다.
- 도구 묶음은 라틴 머리말 TOOL 하나로만 나눈다.
- 열림: 바탕이 150ms에 깔리고 항목이 16px 아래에서 기본 스프링으로 올라온다. 40ms씩, 처음 6개까지.
- 닫힘: 순서 없이 한 번에, `duration-exit`. Esc와 메뉴 버튼으로 닫히고, 열린 동안 뒤 페이지는 스크롤되지 않는다.

## 하지 않는 것
- 시트나 서랍으로 열기, 항목 사이 구분선, 항목마다 화살표, 실버 항목 글자.
