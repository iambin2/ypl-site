# MobileMenu

1024px 미만에서 버거를 누르면 헤더 아래 화면 전체를 덮는 큰 글자 목록. 2026-10-06 보드의 A안으로 정했다(B 인셋 그룹, C 떠 있는 시트는 채택하지 않음).

## 쓰는 법
- 소비자가 주는 것: 현재 페이지, 홈과 페이지 목록, 도구 목록, 아래쪽 행동 둘(디스코드 참여, 관리자 로그인).
- 항목은 `title-2` 폰 크기 24/800, 높이 48. 현재 페이지는 `fill` 캡슐 면. 캡슐은 글자보다 12px 바깥으로 나가 글자가 왼쪽 축을 지킨다.
- 도구 묶음은 `label` 13/600 `text-3` 머리 하나로만 나눈다. 구분선은 쓰지 않는다.
- 아래 행동은 기본 캡슐(디스코드 참여)과 토널 캡슐(관리자 로그인), 44px.
- 열림: 바탕이 150ms에 깔리고, 항목이 16px 아래에서 기본 스프링으로 올라온다. 읽는 순서대로 40ms씩, 처음 6개까지만 순서를 준다.
- 닫힘: 순서 없이 한 번에, 0.7배 빠르게(`duration-exit`). Esc와 버거로 닫히고, 열려 있는 동안 뒤 페이지는 스크롤되지 않는다.
- 동작 줄이기가 켜져 있으면 올라오는 움직임 없이 150ms 크로스페이드.

## 하지 않는 것
- 시트나 서랍으로 열기. 시트는 짧은 입력과 확인의 자리다.
- 항목 사이 구분선, 항목마다 화살표 아이콘.
- 도구를 접어 두기. 아홉 곳뿐이라 모두 펼친다.
