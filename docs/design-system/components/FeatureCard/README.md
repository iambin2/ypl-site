# FeatureCard

한 페이지에 하나뿐인 주인공 카드. 현재 챔피언, 랭킹 1위, 끝난 대진표의 우승자가 이 모양이다.

## 쓰는 법
- 소비자가 주는 것: 머리말(6TH CHAMPION, RANK 1), 이름, 한 줄 설명, 워터마크 숫자, 내용(파티 받침 여섯 칸 또는 점수와 성적 칸).
- 유리 면, `radius-xl`, 안쪽 24 14 14(데스크톱 30 22 22).
- 이름은 `feature-name`(38, 데스크톱 52) 900 실버. 한 화면에서 가장 큰 실버.
- 워터마크 숫자는 오른쪽 위에 걸쳐 카드에 잘린다. `watermark`(150, 데스크톱 210), 실버, 투명도 0.3, `aria-hidden`.
- 랭킹 1위는 이름 아래 `score`(64, 데스크톱 88) 실버 점수와 성적 칸 셋(우승, 준우승, 4강, `fill-2`, `radius-md`).
- 데스크톱에서 커서 빛을 받는다(`ypl-follow`): 커서 자리가 밝아지고 이름과 워터마크의 실버가 함께 흐른다.
- 안의 칸 반경은 동심 계산(32 − 14 = 18).

## 하지 않는 것
- 한 화면에 피처 카드 둘.
- 거울 반사, 금속 광택, 왕관이나 트로피 아이콘.
