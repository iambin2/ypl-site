# Button

모든 행동은 캡슐 버튼 하나로 한다. 기본(`ink`), 토널(`fill`), 조용한, 리드 타일 위(`on-lead`), 위험(`danger`) 다섯 가지.

## 쓰는 법
- 소비자가 주는 것: 버튼 글자(행동 그대로), 선택적으로 뒤쪽 화살표 아이콘, 비활성 여부, 처리 중 여부.
- 한 화면의 주된 행동 하나만 기본 버튼. 나머지는 토널이나 조용한 버튼.
- 크기는 셋: 52(히어로와 리드 타일), 44(기본), 36(관리자 도구와 좁은 곳). 폰에서 주된 버튼은 전체 폭.
- 처리 중에는 폭을 유지하고 글자 자리에 16px 진행 표시. 두 번 눌리지 않는다.
- 되돌릴 수 없는 행동만 위험 버튼. 확인 대화상자의 오른쪽에.

## 하지 않는 것
- 각진 버튼, 외곽선만 있는 버튼, 그림자 있는 버튼.
- "확인", "OK"처럼 행동이 없는 글자.
