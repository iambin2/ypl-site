# Button

모든 행동은 캡슐 버튼 하나로 한다. 주 버튼, 유리 버튼, 조용한 버튼, 위험 버튼 네 가지와 원형 아이콘 버튼.

## 쓰는 법
- 소비자가 주는 것: 버튼 글자(행동 그대로), 선택적 아이콘, 비활성 여부, 처리 중 여부.
- 주 버튼(`ypl-btn--primary`)은 평평한 밝은 면(`primary-top`에서 `primary-bottom`)에 `on-primary` 글자와 `shadow-primary`. 한 화면의 주된 행동 하나에만.
- 유리 버튼(`ypl-btn--glass`)은 보조 행동. 히어로의 "리그 소개"처럼.
- 크기는 셋: 50(폰 기본, 데스크톱 54), 40(`--sm`, 좁은 곳과 관리자 도구), 조용한 버튼 44.
- 아이콘 버튼(`ypl-iconbtn`)은 44px 원, `fill` 면, 18px 아이콘, 접근 가능한 이름.
- 처리 중에는 폭을 유지하고 글자 자리에 16px 진행 표시.
- 되돌릴 수 없는 행동만 위험 버튼.

## 하지 않는 것
- 실버 그라데이션으로 칠한 버튼, 금속 광택 버튼.
- 외곽선만 있는 버튼, 각진 버튼.
- "확인", "OK"처럼 행동이 없는 글자.
