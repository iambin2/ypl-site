# 09 상호작용 상태

상태마다 규칙은 하나다. 버튼, 카드, 행, 입력창, 탭 모두 같은 규칙을 따른다.

| 상태 | 규칙 |
|---|---|
| 호버 | 유리 카드: 2px 떠오르고 윗면이 `glass-hover`로 밝아진다, 화살표 원 2px 밀림. 버튼과 링크: 색이나 면이 한 단계 밝아진다. 마우스가 있는 기기에서만 |
| 누름 | 컨트롤 0.97배, 카드와 행 0.985배. 90ms에 눌리고 경쾌 스프링으로 돌아온다 |
| 포커스 | 키보드로 왔을 때만. `focus` 색 2px 링, 2px 띄워서, 요소의 곡률 그대로 |
| 선택 | 여럿 중 하나: 세그먼트처럼 주 버튼 면(`primary-top`에서 `primary-bottom`)과 `shadow-thumb`. 보조 필터는 `fill`로 한 단계 진하게 |
| 현재 위치 | 내비게이션의 현재 페이지는 `fill` 캡슐 면, 글자 `ink` 700 |
| 승자 | 대진표 승자 칸과 현재 쪽 번호: 주 버튼 면에 `on-primary` 글자 |
| 비활성 | `opacity-disabled`(38%), 금지 커서, 호버와 누름에 반응하지 않는다. 가능하면 이유를 옆에 적는다 |
| 흐림 | 있지만 아직 정해지지 않은 것(미정 경기, 빈 슬롯): `opacity-dim`(45%) |
| 로딩 | 300ms 안에 끝나면 아무것도 보이지 않는다. 넘으면 완성될 모양 그대로의 스켈레톤 |
| 오류 | `danger` 글자와 아이콘, 무엇이 잘못됐고 어떻게 고치는지 한 문장 |

## 세부

- 호버할 것처럼 보이는 것은 모두 호버에 반응한다. 같은 종류 중 하나만 반응하지 않는 일은 없다. 기능 카드 여섯, 결과 행 셋 모두 같은 반응.
- 버튼이 처리 중이면 폭을 유지한 채 글자 자리에 16px 원형 진행 표시. 두 번 눌리지 않는다.
- 입력창 포커스: 바탕이 `bg`로, 테두리가 `ink`로, 4px 바깥 후광(`fill`).
- 툴팁과 호버 미리보기는 이웃 요소를 가리지 않는다.
- 터치 기기에서는 호버 상태를 만들지 않는다(`@media (hover: hover)`).
