# 07 깊이와 빛

깊이는 빛 하나에서 나온다. 페이지마다 광원이 하나 있고, 유리 면은 그 빛을 윗변으로 받는다.

## 층은 셋

| 층 | 만드는 것 | 쓰는 곳 |
|---|---|---|
| 페이지 | `bg`, 광원(`page-light`), 결(`grain`) | 바탕 |
| 유리 | `--glass` 그라데이션과 `shadow-glass` | 카드, 목록, NOW 띠, 피처 카드, 보조 버튼 |
| 떠 있음 | `surface`와 `shadow-pop` 또는 `shadow-float` | 메뉴, 드롭다운, 대화상자, 시트, 토스트 |

## 광원

- 폰: 화면 위 가운데에서 아래로 퍼지는 타원(`ellipse 110% 420px at 50% 60px`).
- 데스크톱: 오른쪽 위(`ellipse 60% 640px at 72% 120px`). 왼쪽의 큰 문구 옆 빈 자리를 빛이 채운다.
- 광원은 페이지에 하나. 섹션마다 빛을 새로 깔지 않는다.
- 결(`grain`)은 1px 점의 반복으로 아주 옅게. 사진 같은 노이즈 이미지는 쓰지 않는다.

## 그림자

- `shadow-glass`: 유리 면의 윗변 빛, 아랫변 그늘, 바닥 그림자를 한 번에.
- `shadow-primary`: 주 버튼.
- `shadow-thumb`: 세그먼트 선택 칸과 고른 포켓몬 슬롯.
- `shadow-pop`, `shadow-float`: 떠 있는 층. 다크에서는 1px 흰 테두리 빛을 함께 가진다.

## 겹침 순서

| 토큰 | 층 |
|---|---|
| `z-content` | 화면 흐름 |
| `z-sticky` | 상단 내비게이션 |
| `z-popover` | 메뉴, 드롭다운 |
| `z-modal` | 배경 어둡게와 대화상자, 시트, 전체 메뉴 |
| `z-toast` | 토스트 |

## 규칙

- 배경 어둡게(`scrim`)는 한 번에 하나.
- 흐림은 두 곳에만: 상단 내비게이션 바탕(`saturate(180%) blur(20px)`, `::before`에), 배경 어둡게(8px).
- 등장이 끝난 요소에 transform이나 opacity를 남기지 않는다(`animation-fill-mode: backwards`).
