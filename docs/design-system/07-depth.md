# 07 깊이와 레이어

화면 흐름 안의 모든 것은 평평하다. 깊이는 면의 밝기 단계(`bg`, `bg-2`, `bg-3`)와 리드 타일의 반전으로만 만든다. 그림자는 정말로 떠 있는 층에만 있다.

## 그림자는 두 단계

| 토큰 | 쓰는 곳 |
|---|---|
| `shadow-pop` | 메뉴, 드롭다운, 툴팁 |
| `shadow-float` | 대화상자, 시트, 토스트 |

`shadow-thumb`은 세그먼트의 선택 칸 하나에만 쓴다. 눌러서 옮기는 실물 스위치처럼 보이게 하는 유일한 예외다. 다크 테마의 그림자는 검정 위에서도 층이 구분되도록 흰 테두리 0.5~1px을 함께 가진다.

## 겹침 순서는 다섯 층

| 토큰 | 층 |
|---|---|
| `z-content` | 화면 흐름 |
| `z-sticky` | 상단 내비게이션 |
| `z-popover` | 메뉴, 드롭다운, 툴팁 |
| `z-modal` | 배경 어둡게와 대화상자, 시트, 전체 메뉴 |
| `z-toast` | 토스트 |

## 규칙

- 배경 어둡게(`scrim`)는 한 번에 하나. 대화상자 위에 대화상자가 열리면 바뀌어 들어가고 배경은 겹치지 않는다.
- 흐림은 두 곳에만: 상단 내비게이션 바탕(`saturate(180%) blur(20px)`), 배경 어둡게(8px).
- 상단 내비게이션의 흐림은 내비게이션 요소 자체가 아니라 그 `::before`에 건다. 그래야 그 안에 고정된 전체 메뉴가 화면 기준으로 열린다.
- 등장이 끝난 요소에 transform이나 opacity를 남기지 않는다(`animation-fill-mode: backwards`). 남으면 새 겹침 맥락이 생겨 대화상자가 내비게이션 아래로 깔린다.
