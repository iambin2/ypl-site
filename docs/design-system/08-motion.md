# 08 모션

시간과 곡선을 따로 고르지 않는다. 반응 시간과 감쇠, 두 값으로 정한 스프링 세 개만 쓴다. 눌러보며 확인하는 페이지: [YPL 모션 규칙](https://claude.ai/artifact/JSU9NQfdsyBiaxDkd6Hgta)

## 스프링 세 개

| 스프링 | 반응 | 감쇠 | 멈추기까지 | 쓰는 곳 |
|---|---|---|---|---|
| 경쾌 | 0.34초 | 0.72 | `duration-snappy` 406ms | 누름 복귀, 탭 표시기, 토글, 체크 |
| 기본 | 0.42초 | 1 | `duration-smooth` 566ms | 등장, 이동, 메뉴, 숫자 굴림 |
| 여유 | 0.55초 | 1 | `duration-gentle` 741ms | 시트, 전체 메뉴, 화면 전환 |

감쇠 1인 스프링은 곡선 모양이 모두 같고 길이만 다르다. 그래서 곡선은 두 개뿐이다.

```css
/* 감쇠 1: 기본, 여유, 모든 퇴장 */
--ease-spring: linear(0, 0.0195, 0.0679, 0.1336, 0.2081, 0.2857, 0.3625, 0.4361, 0.5047, 0.5677, 0.6247, 0.6757, 0.7209, 0.7606, 0.7953, 0.8255, 0.8517, 0.8742, 0.8935, 0.91, 0.9241, 0.9361, 0.9463, 0.9549, 0.9622, 0.9683, 0.9735, 0.9779, 0.9815, 0.9846, 0.9872, 0.9893, 0.9911, 0.9926, 0.9939, 0.9949, 0.9958, 0.9965, 0.9971, 0.9976, 1);
/* 감쇠 0.72: 경쾌, 3.8%까지 넘쳤다 돌아옴 */
--ease-snappy: linear(0, 0.0161, 0.0586, 0.12, 0.1939, 0.2751, 0.3593, 0.4433, 0.5246, 0.6012, 0.672, 0.7361, 0.7931, 0.843, 0.8859, 0.9221, 0.9522, 0.9766, 0.996, 1.0109, 1.0219, 1.0297, 1.0347, 1.0374, 1.0384, 1.0379, 1.0364, 1.0342, 1.0314, 1.0283, 1.025, 1.0218, 1.0187, 1.0157, 1.013, 1.0105, 1.0082, 1.0063, 1.0046, 1.0032, 1);
/* 색과 투명도 */
--ease-fade: cubic-bezier(.2, .8, .2, 1);
```

## 열 가지 법칙

1. **스프링은 세 개뿐.** 위 표 밖의 시간과 곡선은 쓰지 않는다.
2. **시간은 거리와 크기에서 나온다.** 색, 투명도, 그림자는 `duration-fade`(150ms). 컨트롤 안의 작은 이동은 경쾌, 요소는 기본, 화면 크기의 표면은 여유.
3. **퇴장은 등장보다 빠르다.** 반응 시간의 0.7배, 튕김 없이: `duration-exit` 396ms, `duration-exit-gentle` 519ms.
4. **나온 곳에서 나오고 나온 곳으로 돌아간다.** 메뉴는 누른 버튼 모서리에서 0.9배로 자라나고, 대화상자는 중앙에서 0.96배로, 시트는 아래에서.
5. **누르면 눌린다.** 컨트롤 0.97배, 타일 0.985배. 누르는 순간 `duration-press`(90ms), 떼면 경쾌 스프링.
6. **읽는 순서대로 등장한다.** 행 사이 40ms, 타일 사이 60ms. 처음 6개까지만 순서를 주고 전체는 0.4초 안. 등장 거리 16px. 한 번 등장한 것은 다시 등장하지 않는다.
7. **숫자는 굴러서 바뀐다.** 값이 바뀌면 바뀐 자리만 세로로 굴린다. 처음 열 때 0부터 세어 올리지 않는다.
8. **언제든 방향을 바꿀 수 있다.** 상태 변화는 transition으로만. 키프레임은 등장에만.
9. **움직이는 것은 위치와 크기와 투명도뿐.** transform과 opacity만. 무한 반복은 "접수 중" 맥박 하나(2초 주기).
10. **동작 줄이기를 존중한다.** 기기 설정이 켜져 있으면 모든 이동과 크기 변화는 150ms 크로스페이드, 순서 등장과 숫자 굴림과 맥박은 멈춘다.

## 쓰지 않는 것

패럴랙스, 스크롤 가로채기, 자동으로 넘어가는 슬라이드, 강조를 위한 색 깜빡임, 본문 글자의 등장 연출, 호버에서의 이동과 확대(화살표 2px 밀림만 예외).
