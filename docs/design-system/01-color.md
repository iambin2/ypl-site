# 01 색

YPL은 무채색만 쓴다. 검정, 흰색, 회색 위에서 강조는 크기와 반전이 맡는다. 색이 있는 것은 의미를 싣는 상태색과, 게임 데이터인 포켓몬 타입색뿐이다.

## 면의 단계

| 단계 | 토큰 | 쓰는 곳 |
|---|---|---|
| 0 | `bg` | 페이지 바탕 |
| 1 | `bg-2` | 타일, 인셋 그룹, 빈 상태 |
| 2 | `bg-3` | `bg-2` 위의 호버, `bg-2` 안의 입력창 |
| 반전 | `lead`, 안쪽은 `lead-2` | 리드 타일: 다음 행동, 현 챔피언 |
| 떠 있음 | `surface` | 메뉴, 대화상자, 시트, 토스트 |

- 면은 한 번에 한 단계만 올린다. `bg` 위에 `bg-3`을 바로 놓지 않는다.
- 리드 타일은 한 화면에 하나. 라이트에서는 잉크로 반전되고, 다크에서는 한 단계 밝은 면이 된다.
- 리드 타일 안의 글자는 `on-lead`와 `on-lead-2`, 칩과 보조 버튼은 `lead-fill`.

## 글자의 단계

- `ink`: 제목, 본문, 목록 이름.
- `text-2`: 보조 본문, 쉬는 상태의 내비게이션.
- `text-3`: 메타 줄, 라벨, 단위, 자리표시 글자.
- `on-ink`: `ink` 바탕(기본 버튼, 우승 칸, 1위 배지) 위의 글자.

## 강조는 반전으로

우승, 1위, 현재 선택처럼 하나만 서는 것은 `ink` 바탕에 `on-ink` 글자로 반전한다. 금색, 파란색, 강조색 틴트는 없다.

## 상태색

`ok`, `warn`, `danger`는 의미가 있을 때만 쓰고, 언제나 글자나 아이콘을 함께 붙인다. 색만으로 상태를 알리지 않는다. `danger`는 오류와 되돌릴 수 없는 행동에만 쓰는 사이트의 유일한 빨강이다.

## 포켓몬 타입색

`type-*` 18색은 팀 빌더의 타입 배지에만 쓴다. 타일, 제목, 차트에 번지지 않는다. 밝은 다섯 타입(전기, 얼음, 비행, 바위, 페어리)은 흰 글자 대신 `type-*-text`를 쓴다.

## 하지 않는 것

- 흰색과 검정을 직접 쓰지 않는다. 언제나 토큰으로, 그래야 두 테마가 함께 바뀐다.
- 그라데이션을 쓰지 않는다.
- 색으로 섹션을 구분하지 않는다.
