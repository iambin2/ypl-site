# 13 반응형

구간은 셋뿐이다. 폰을 먼저 설계하고 넓은 화면은 같은 요소를 펼친다.

| 구간 | 폭 | 바뀌는 것 |
|---|---|---|
| 폰 | 640 미만 | 헤더 60, 메뉴 버튼과 전체 메뉴, 기능 카드 2열, 파티 3열, 하단 시트 |
| 태블릿 | `bp-tablet` 640 이상 | 기능 카드 3열, 시트가 가운데 대화상자로 |
| 데스크톱 | `bp-desktop` 1024 이상 | 헤더 72와 가로 내비게이션, 데스크톱 글자 크기, 파티 6열, 챔피언과 결과 7:5, 커서 빛 |

## 규칙

- 이 둘 밖의 중단점을 만들지 않는다. 요소가 좁아서 깨지면 요소 안에서 컨테이너 쿼리로 해결한다.
- 글자 크기는 구간마다 고정(02 서체). 폰 값과 데스크톱 값 두 개뿐이고 태블릿은 폰 값.
- 데스크톱 히어로는 문구 혼자 왼쪽에 서고, 오른쪽 빈 자리는 광원이 채운다. 그림이나 엠블럼으로 채우지 않는다.
- 어떤 폭에서도 페이지가 가로로 스크롤되지 않는다. 대진표만 자기 판 안에서 가로로 스크롤된다.
- 폰 하단에 고정되는 요소는 안전 영역만큼 띄운다.
