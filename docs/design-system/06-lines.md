# 06 선과 면

선은 최소로, 면이 대신한다. 직각으로 끝나는 굵은 선은 연속 곡률과 부딪히고 화면을 날카롭게 자른다.

## 섹션은 공백으로 나눈다

섹션 사이에 괘선을 긋지 않는다. 섹션 간격(05 배치와 공백)과 `title-2` 제목이 경계를 만든다.

## 목록은 인셋 그룹에 담는다

랭킹, 공지, 게시글, 기록 표처럼 행이 이어지는 것은 `bg-2` 면 하나(`radius-lg`)에 담는다.

- 면의 안쪽 좌우 여백은 `space-4`(16).
- 행 사이 구분선은 `stroke-hairline`(0.5px), 색은 `line`.
- 구분선은 행의 글자가 시작하는 지점에서 시작한다. 순위 숫자가 있으면 그 뒤에서. 면의 둥근 가장자리에 닿지 않는다.
- 첫 행 위와 마지막 행 아래에는 선을 긋지 않는다.
- 인셋 그룹 안에 또 다른 면이나 카드를 넣지 않는다.

## 선이 남는 곳

| 선 | 굵기 | 끝 |
|---|---|---|
| 인셋 구분선 | 0.5px | 면 안에서 끝남 |
| 리드 타일 안 사실 목록 | 0.5px, `lead-line` | 면 안에서 끝남 |
| 대진표 연결선 | 1.5px | 둥근 끝, 꺾이는 곳은 8px 둥글게 |
| 아이콘 획 | 2px | 둥근 끝, 둥근 이음 |
| 포커스 링 | 2px | 요소의 곡률을 따름 |

이 다섯 가지 밖의 선은 없다.

## 하지 않는 것

- 3px 괘선, 섹션 머리의 굵은 선.
- 카드 위나 왼쪽 가장자리의 강조 띠.
- 패널을 두르는 외곽선, 둥근 타일 묶음을 다시 두르는 외곽선.
- 화면 끝에서 끝까지 이어지는 구분선.
- 탭 아래 밑줄 표시. 선택은 캡슐 면(세그먼트의 선택 칸)으로 표시한다.
