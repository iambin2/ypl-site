# 14 접근성

## 대비

- 글자는 바탕 대비 4.5:1 이상, 24px 이상이나 굵은 19px 이상은 3:1 이상. 두 테마 모두.
- `text-3`은 `bg`와 `bg-2` 위에서 4.5:1을 넘는다. `bg-3` 위의 작은 글자에는 `text-2` 이상을 쓴다.
- 의미를 싣는 아이콘, 포커스 링, 입력창 테두리는 3:1 이상.
- 상태는 색만으로 알리지 않는다. 언제나 글자나 아이콘을 함께.

## 조작

- 모든 기능은 키보드로 쓸 수 있다. 포커스 순서는 읽는 순서.
- 포커스 링은 지우지 않는다(09 상호작용 상태).
- 탭 대상은 최소 44px, 대상 사이 8px 이상.
- Esc는 가장 위의 층 하나만 닫는다. 닫히면 포커스는 그 층을 연 요소로 돌아간다.

## 읽기

- 페이지 언어는 한국어(`lang="ko"`).
- 포스터 숫자와 수치에는 뜻을 담은 라벨: "D-5"는 "5일 남음".
- 아이콘만 있는 버튼에는 접근 가능한 이름.
- 실시간으로 바뀌는 대진과 점수는 `aria-live="polite"`.

## 움직임

- 기기의 동작 줄이기 설정을 따른다(08 모션 10번 법칙).
- 깜빡임은 없다. 무한 반복은 "접수 중" 맥박 하나.
