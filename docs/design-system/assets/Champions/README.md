# 우승 파티 아트워크

6대 챔피언 김현민(YPL 시즌 2)의 우승 파티 여섯 마리. 사이트의 `public/champions/g9usuez-0.png`부터 `-5.png`까지와 같은 파일이다. 법전의 FeatureCard, PartyPod, PokemonSlot 미리보기가 이 그림을 쓴다.

- 슬롯 순서: 한카리아스, 망나뇽, 삼삼드래, 킬가르도, 메타그로스, 누리레느.
- 투명 배경 PNG, 긴 변 180px. 받침 칸 위에 `contain`으로 놓는다(11 포켓몬 이미지).
- 현재 챔피언이 바뀌면 이 묶음도 새 우승 파티로 바꾼다.
