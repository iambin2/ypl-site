# 로고

`newlogo.svg`: 워글(Braviary) 마크. 원본 `docs/brand/newlogo.png`를 potrace로 그대로 옮긴 단색 벡터다. 잉크는 검정(#000) 한 가지이고 흰 부분은 뚫려 있다.

- 사이트에서는 `ink` 색으로 칠해 쓴다. 라이트에서는 검정, 다크에서는 밝은 회색으로 함께 바뀐다. `<img>`로 넣으면 색을 바꿀 수 없으므로 사이트 코드에서는 인라인 SVG로 쓴다.
- 비율 1092:647. 헤더 높이 30px(폰 26px), 푸터 26px.
- 다시 그리거나, 비율을 바꾸거나, 색을 입히지 않는다. 원본이 바뀌면 다시 벡터로 옮긴다.
- 파비콘은 같은 마크를 `ink` 연속 곡률 타일 위에 흰색으로.
