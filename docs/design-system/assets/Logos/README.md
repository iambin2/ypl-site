# 로고

`newlogo.svg`: 워글(Braviary) 마크. 원본 `docs/brand/newlogo.png`를 potrace로 그대로 옮긴 단색 벡터다. 흰 부분은 뚫려 있다.

- 사이트에서는 이 벡터를 CSS 마스크로 쓰고 실버 그라데이션(`--silver`)을 채운다. 다크에서는 흰 은색, 라이트에서는 강철색으로 함께 바뀐다.
- 비율 1092:647. 헤더 높이 24px(데스크톱 27px), 푸터 24px.
- 다시 그리거나, 비율을 바꾸거나, 다른 색을 입히지 않는다. 원본이 바뀌면 다시 벡터로 옮긴다.
- 홈 첫 화면에 큰 엠블럼으로 세우지 않는다. 로고는 헤더와 푸터의 서명이다.
- 파비콘은 같은 마크를 `bg` 연속 곡률 타일 위에 실버로.
