# 15 문구

리그의 공식 사이트로서 평이하고 정확한 한국어 문장으로 쓴다.

## 규칙

- **가운뎃점(·)으로 사실을 잇지 않는다.** 쉼표와 조사로 문장을 쓴다. "팀전·싱글·8명"이 아니라 "팀전, 싱글 엘리미네이션, 8명".
- **소개 문장은 한 줄.** 노트북 화면에서 한 줄에 들어가게 짧게 쓴다. 의미 없는 줄바꿈을 넣지 않는다.
- **공식 톤.** 팬 사이트 말투, 감탄, 구호("기록으로 남는 배틀…")를 쓰지 않는다.
- **버튼은 행동 그대로.** "파티 제출하기", "공지 읽기", "다시 불러오기". "확인"과 "OK"를 남발하지 않는다.
- **오류는 원인과 해결.** 무엇이 잘못됐는지, 어떻게 하면 되는지. 사과하지 않는다.
- **회원이 아는 이름으로.** 내부 용어(런타임, 스냅샷, 엔트리)를 화면에 쓰지 않는다. 대회, 대진, 파티, 기록.
- **영어를 섞지 않는다.** 화면 문구는 한국어. 고유명사(YPL, 디스코드)만 예외.
- **채널의 역할.** 공지와 기록의 첫 출처는 이 사이트다. 디스코드는 배틀과 중계가 열리는 곳이다. "배틀과 중계는 디스코드에서 열립니다."
- **허수 통계를 만들지 않는다.** 회원 수 같은 규모 숫자를 장식으로 쓰지 않는다. 숫자는 기록에서 나온 것만.

## 예

| 쓰지 않음 | 씀 |
|---|---|
| 대진 확정·결과 반영 | 대진이 확정되면 결과가 기록에 반영됩니다 |
| 제출 실패! 다시 시도해주세요 ㅠㅠ | 제출하지 못했습니다. 연결을 확인하고 다시 제출하세요 |
| Party Submit | 파티 제출하기 |
| 기록으로 남는 배틀, YPL | 포켓몬 센터 연세점 공식 배틀 리그 |

## 법적 고지

푸터의 고지는 그대로 둔다: 비공식 팬 사이트이며 포켓몬 상표는 Nintendo, Creatures, GAME FREAK에 있다.
