YPL(Yonsei Pokémon League)은 포켓몬 센터 연세점의 공식 배틀 리그 사이트다. 회원은 주로 폰으로, 평소에도 대회 당일 현장에서도 공지를 읽고, 참가를 신청하고, 파티를 제출하고, 대진과 기록을 확인한다. 이 법전은 그 사이트의 모든 화면과 모든 작은 요소가 따르는 하나의 법칙이다.

방향은 한 문장이다. **표면은 리그 공식 사이트의 정석, 위계는 대회장 게시지처럼.** 무채색 면과 연속 곡률 위에서, 화면마다 숫자 하나가 포스터 크기로 선다.

## 다섯 가지 원칙

1. **다음 행동이 먼저.** 첫 화면은 지금 대회 단계에서 회원이 할 일 하나와 그 버튼을 보여준다. 나머지는 그 아래로 물러난다.
2. **기록은 사실처럼.** 날짜, 순위, 점수는 콘덴스드 숫자로 크게, 고정폭으로, 꾸밈 없이 세운다.
3. **색 대신 크기와 반전.** 브랜드 색은 없다. 강조는 크기, 굵기, 위치, 잉크 반전(`ink` 바탕에 `on-ink` 글자)으로만 한다.
4. **하나의 법칙.** 같은 역할의 요소는 크기, 위치, 서체, 곡률, 움직임이 모두 같다. 토큰에 없는 값은 쓰지 않는다.
5. **폰이 기준.** 대회장의 폰 화면에서 한 손으로, 빠르게 끝나야 한다. 데스크톱은 같은 요소를 넓게 펼친 것이다.

## 꼭 지킬 규칙

- 면은 `bg` → `bg-2` → `bg-3` 순서로 한 단계씩만 올린다. 리드 타일만 `lead`로 반전한다.
- 글자는 `ink`, `text-2`, `text-3` 세 단계. 메타 줄과 단위는 `text-3`.
- 한글과 영문은 `sans`(원티드 산스), 비교하는 숫자는 `num`(소피아 산스 엑스트라 콘덴스드). 굵기는 400, 600, 800만.
- 포스터 숫자(`poster`)는 화면당 하나. 나머지 숫자는 `figure`와 `date` 두 단계.
- 모든 모서리는 연속 곡률. 반경은 `radius-*`의 기준값을 1.6배로 늘리고 `superellipse(1.78)`로 그린다. 캡슐은 원형 끝.
- 안쪽 반경 = 바깥 반경 − 여백. 같은 반경을 겹치지 않는다.
- 간격은 `space-1`부터 `space-11`까지 열한 값뿐. 안쪽 간격은 언제나 바깥 간격보다 좁다.
- 섹션은 공백으로 나눈다. 굵은 괘선과 박스 외곽선은 쓰지 않는다. 목록은 `bg-2` 인셋 그룹에 담고 행 사이는 `stroke-hairline` 인셋 구분선.
- 그림자는 떠 있는 층에만: `shadow-pop`, `shadow-float`. 세그먼트 선택 칸의 `shadow-thumb`이 유일한 예외.
- 움직임은 스프링 세 개(`duration-snappy`, `duration-smooth`, `duration-gentle`)와 그 퇴장값뿐. 움직이는 속성은 transform과 opacity.
- 문구는 평이한 한국어 문장. 가운뎃점(·)으로 사실을 잇지 않는다.
