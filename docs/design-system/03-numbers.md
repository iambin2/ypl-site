# 03 숫자와 표기

같은 종류의 정보는 사이트 어디서나 같은 형식으로 쓴다.

| 정보 | 형식 | 예 |
|---|---|---|
| 전체 날짜 | 연.월.일, 두 자리 채움 | 2026.10.01 |
| 메타 줄의 날짜 | 연 월 | 2026년 7월 |
| 같은 해 안의 날짜 | 월.일 요일 한 글자 | 10.11 토 |
| 시각 | 24시간제 | 19:00 |
| 기간 | 물결표 양쪽 공백 | 10.09 ~ 10.11 |
| 남은 날 | D-숫자, 당일은 D-DAY | D-5 |
| 회차와 대수 | 숫자 뒤 작은 단위 | 36회, 6대 |
| 순위 | 숫자만, 같은 점수는 같은 순위 | 6, 6, 8 |
| 점수 | 숫자 뒤 작은 단위 | 410점 |
| 성적 요약 | 띄어 나열 | 우승 3 준우승 5 4강 3 |
| 시즌 | 한글 | YPL 시즌 3 |

## 숫자의 목소리

- 따로 서는 숫자는 `latin`(언바운디드), 고정폭(`tabular-nums`).
- 실버 숫자: 결과 목록의 회차, 2~3위 순위, 피처 카드의 `score`와 `watermark`.
- 흰 숫자(`ink`): 성적 칸, 목록의 점수. 4위 아래 순위는 `text-2`.

## 단위

- 큰 숫자 옆 단위는 `sans` 700, 숫자의 기준선에 맞춰 붙인다. 회차의 "회"는 11px, 점수의 "점"은 12~14px, 색 `text-3`.
- 문장 속에서는 단위를 따로 작게 하지 않는다.

## 정렬

- 숫자 열은 오른쪽 정렬, 고정폭.
- 순위 숫자 열의 폭은 같은 목록 안에서 같다(폰 28px, 회차 44px, 데스크톱 54px).
- 동점은 같은 순위를 주고 다음 순위를 건너뛴다(6, 6, 8).

## 화면 낭독기

큰 숫자에는 뜻을 담은 라벨: "410"은 "410점", 워터마크 "6"은 장식이라 `aria-hidden`.
