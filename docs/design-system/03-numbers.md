# 03 숫자와 표기

같은 종류의 정보는 사이트 어디서나 같은 형식으로 쓴다.

| 정보 | 형식 | 예 |
|---|---|---|
| 전체 날짜 | 연.월.일, 두 자리 채움 | 2026.10.01 |
| 같은 해 안의 날짜 | 월.일 요일 한 글자 | 10.11 토 |
| 시각 | 24시간제 | 19:00 |
| 날짜와 시각 | 월.일 요일 시각 | 10.11 토 19:00 |
| 기간 | 물결표 양쪽 공백 | 10.09 ~ 10.11 |
| 남은 날 | D-숫자, 당일은 D-DAY | D-5 |
| 게시글 시각 | 7일 안은 상대 시각, 그 뒤는 날짜 | 3시간 전, 2026.08.18 |
| 회차와 대수 | 숫자와 단위를 붙여 | 37회, 6대, 1위 |
| 점수 | 숫자 뒤 작은 단위 | 410점 |
| 큰 수 | 천 단위 쉼표 | 1,240 |
| 성적 요약 | 쉼표로 나열 | 우승 3, 준우승 5, 4강 3 |
| 시즌 | 한글 | YPL 시즌 3 |

## 단위

- 큰 숫자 옆 단위는 `label` 스타일(13px, 600, `text-3`)로 숫자의 기준선에 맞춰 붙인다. 숫자와 단위 사이는 `space-1`.
- 문장 속에서는 단위를 따로 작게 하지 않는다. "410점을 얻었다"처럼 그대로 쓴다.

## 정렬

- 숫자 열은 오른쪽 정렬, 고정폭.
- 포스터 숫자는 글자 옆 여백만큼 왼쪽으로 당겨(약 -0.03em) 왼쪽 축에 맞춘다.
- 순위 숫자 열의 폭은 같은 목록 안에서 같다.

## 화면 낭독기

포스터 숫자에는 뜻을 담은 라벨을 붙인다. "D-5"는 "5일 남음", "410"은 "410점".
