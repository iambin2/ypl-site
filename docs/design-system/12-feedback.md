# 12 피드백 상태

빈 상태, 로딩, 오류, 완료는 모두 내용이 놓일 바로 그 자리에서, 그 내용과 같은 모양으로 보여준다.

## 빈 상태

- 내용이 놓일 유리 면 안에서, 왼쪽 축에 맞춰.
- 무엇이 비어 있는지 한 문장(`callout`, `text-2`), 할 수 있는 행동이 있으면 유리 버튼 하나.
- 그림, 이모지, 큰 아이콘을 넣지 않는다.
- 예: "아직 등록된 대회 결과가 없습니다." / "진행 중인 대회가 없습니다. 최근 결과를 확인하세요."
- NOW 띠는 진행 중인 대회가 없으면 그리지 않는다.

## 로딩

- 300ms 안에 끝나면 아무것도 보이지 않는다.
- 넘으면 스켈레톤: 완성될 요소와 같은 크기, 같은 곡률의 `fill` 면. 글자 줄은 캡슐.
- 1.2초 주기로 투명도가 0.5와 1 사이를 오간다. 빛이 지나가는 효과는 쓰지 않는다.

## 오류

- 입력 오류: 필드 바로 아래 `meta` 크기, `danger` 색, alert 아이콘. 무엇이 잘못됐고 어떻게 고치는지. 사과하지 않는다.
- 불러오기 오류: 내용 자리에 한 문장과 "다시 불러오기" 유리 버튼.

## 완료와 토스트

- 화면 안에서 결과가 보이는 행동은 그 자리의 상태 변화로 끝낸다.
- 결과가 보이지 않는 행동만 토스트로: 화면 아래 가운데, 안전 영역 위 16. 주 버튼 면의 캡슐, `shadow-float`. 2.4초 뒤 퇴장. 한 번에 하나.
- 문구는 결과를 그대로: "파티를 제출했습니다", "링크를 복사했습니다".

## 확인 대화상자

- 브라우저 기본 alert, confirm, prompt는 쓰지 않는다.
- 되돌릴 수 없는 행동은 `danger` 버튼을 오른쪽에, 버튼 글자는 행동 그대로.
