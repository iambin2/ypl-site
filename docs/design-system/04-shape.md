# 04 곡률

모든 모서리는 연속 곡률로 그린다. 원형 모서리는 직선이 끝나는 순간 곡률이 계단처럼 뛰어 미세한 꺾임으로 읽힌다. 연속 곡률은 0에서 서서히 차올랐다가 다시 0으로 내려가 직선과 이음매 없이 이어진다.

## 그리는 법

`radius-*`는 기준 반경이다. 연속 곡률을 지원하는 브라우저에서는 1.6배로 늘려 `superellipse(1.78)`로 그린다. 45도 지점의 깊이는 원형과 같고, 곡선이 시작되는 지점만 1.6배 멀어진다.

```css
.sq { border-radius: var(--r); }
@supports (corner-shape: squircle) {
  .sq { border-radius: calc(var(--r) * 1.6); corner-shape: superellipse(1.78); }
}
```

지원하지 않는 브라우저(현재 iOS 사파리)는 같은 기준 반경의 원형으로 그린다. 크기는 같고 이음매만 다르다. 지원이 나오면 코드 수정 없이 바로 적용된다.

## 반경은 크기에 비례한다

| 토큰 | 기준 | 쓰는 곳 |
|---|---|---|
| `radius-xs` | 6 | 체크박스, 32px 이하 썸네일 |
| `radius-sm` | 10 | 입력창, 메뉴 항목, 아이콘 타일 |
| `radius-md` | 14 | 포켓몬 슬롯, 작은 타일, 경기 카드 |
| `radius-lg` | 20 | 결과 타일, 인셋 그룹, 카드 |
| `radius-xl` | 28 | 리드 타일, 패널, 대화상자 |
| `radius-2xl` | 38 | 폰 하단 시트 |
| `radius-pill` | 캡슐 | 버튼, 칩, 탭, 검색창, 토스트 |

- 1.6배로 늘린 반경이 짧은 변의 절반을 넘으면 곡선이 눌려 사각형처럼 보인다. 그 크기의 요소는 한 단계 작은 반경을 쓴다.
- **캡슐은 예외다.** 끝을 원형으로 둔다. 캡슐에 연속 곡률을 걸면 끝이 각진 사각형처럼 뭉개진다.

## 동심 규칙

안에 놓인 요소의 반경은 바깥 반경에서 여백을 뺀 값이다.

- 리드 타일(`radius-xl` 28) 안쪽 여백 20 → 안쪽 면의 반경 8.
- 폰 하단 시트는 기기 가장자리에서 `space-2`(8) 떨어져 `radius-2xl`(38)로 그린다. 기기 모서리(약 46)와 동심.
- 계산 값이 4보다 작으면 4를 쓴다.
- 같은 반경을 겹치지 않는다. 모서리 틈이 두꺼워 보인다.
- 캡슐은 동심 계산에서 빠진다.

## 포커스 링도 곡률을 따른다

포커스 링은 요소에서 2px 떨어져 반경 + 2, 같은 `corner-shape`로 그린다. 캡슐의 링은 캡슐이다.
