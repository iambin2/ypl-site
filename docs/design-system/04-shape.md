# 04 곡률

모든 모서리는 연속 곡률로 그린다. 원형 모서리는 직선이 끝나는 순간 곡률이 계단처럼 뛰어 미세한 꺾임으로 읽힌다. 연속 곡률은 0에서 서서히 차올랐다가 다시 0으로 내려가 직선과 이음매 없이 이어진다.

## 그리는 법

`radius-*`는 기준 반경이다. 연속 곡률을 지원하는 브라우저에서는 1.6배로 늘려 `superellipse(1.78)`로 그린다.

```css
.ypl-sq { border-radius: var(--r); }
@supports (corner-shape: squircle) {
  .ypl-sq { border-radius: calc(var(--r) * 1.6); corner-shape: superellipse(1.78); }
}
```

지원하지 않는 브라우저는 같은 기준 반경의 원형으로 그린다.

## 반경은 크기에 비례한다

| 토큰 | 기준 | 쓰는 곳 |
|---|---|---|
| `radius-sm` | 12 | 입력창, 메뉴 항목 |
| `radius-md` | 18 | 포켓몬 받침, 성적 칸, 경기 카드, 세그먼트 선택 칸 |
| `radius-lg` | 24 | 기능 카드, 유리 목록, NOW 띠, 2~3위 카드 |
| `radius-xl` | 32 | 피처 카드, 대진표 판, 대화상자 |
| `radius-2xl` | 38 | 폰 하단 시트 |
| `radius-pill` | 캡슐 | 버튼, 칩, 아이콘 버튼, 세그먼트 트랙, 내비게이션 캡슐 |

- 1.6배로 늘린 반경이 짧은 변의 절반을 넘으면 한 단계 작은 반경을 쓴다.
- **캡슐은 예외다.** 끝을 원형으로 둔다.

## 동심 규칙

안에 놓인 요소의 반경은 바깥 반경에서 여백을 뺀 값이다.

- 피처 카드(`radius-xl` 32) 안쪽 여백 14 → 받침 칸 18(`radius-md`).
- 세그먼트 트랙 22, 여백 4 → 선택 칸 18.
- 계산 값이 4보다 작으면 4를 쓴다. 캡슐은 동심 계산에서 빠진다.

## 포커스 링도 곡률을 따른다

포커스 링은 요소에서 2px 떨어져 반경 + 2, 같은 `corner-shape`로 그린다.
