# 사이트 통일성 점검

점검일: 2026-10-07

## 기준과 수정

기존 PRODUCT.md, DESIGN.md, 디자인 법전의 공통 규칙을 기준으로 공개 화면과 관리자 스타일을 검사했다. 기존 문서의 사용자 수정은 보존했다.

| 발견한 차이 | 수정 |
| --- | --- |
| 기본 font 규칙이 공통 입력 규칙보다 우선하여 검색창이 모바일 15px, 데스크톱 17px로 표시됨 | 입력 규칙의 우선순위를 바로잡아 16px로 통일. 곡률, 포커스, 오류 표시와 textarea 규칙도 같은 우선순위로 정리 |
| 작은 버튼, 선택 탭, 닫기와 삭제 도구의 터치 영역이 제각각 | 폰과 터치 기기에서 최소 44px 적용. 관리자 표의 도구 열과 팀 빌더 제거 버튼 공간도 확보 |
| 더 보기 링크와 푸터 링크의 조작 높이가 부족함 | 공통 44px 기준 적용. 섹션 머리 간격을 기존 공간 토큰에 맞춤 |
| 480, 560, 760, 900, 1000px 등 화면별 반응형 기준이 혼재 | 640px와 1024px 경계로 정리. 640px에서 폰과 태블릿 규칙이 겹치던 부분 제거 |
| 기록과 대진표가 빈 상태 마크업을 별도로 구현하고 명예의 전당은 빈 상태 안내가 없음 | 공유 Empty 컴포넌트 사용. 대진표 생성 버튼 유지. 명예의 전당 빈 상태 안내 추가 |
| 댓글 본문 열이 긴 내용에 밀릴 수 있음 | 본문 열의 최소 폭을 0으로 지정 |
| 저장용 대진표 이미지의 강조 그라데이션이 이전 색상 사용 | 현재 다크 테마의 5단계 강조 색상과 위치로 맞춤 |
| 라이브 표시의 맥박 시간이 별도 상수 | 공통 duration-pulse 토큰 사용 |

## 검증

- 홈, 소개, 공지, 게시판, 기록, 대진표, 팀 빌더, 칭호, 명예의 전당: 390 / 640 / 1024 / 1280px × 다크 / 라이트, 총 72개 조합 검사. 페이지 가로 넘침, 작은 입력 글자, 폰의 44px 미만 버튼 없음.
- 마지막 반응형 조정 후 소개, 대진표, 팀 빌더를 320 / 639 / 640 / 1023px에서 추가 검사. 가로 넘침 없음.
- 게시판 글쓰기 시트, 기록 4개 탭 전환, 팀 빌더 포켓몬 선택과 제거 버튼 영역 검사. 제거 버튼 44×44px이며 이름과 겹치지 않음.
- 동작 줄이기 설정에서 배경 애니메이션 중지 확인.
- 전체 회귀 테스트 278개 통과. 프로덕션 빌드 성공. git diff --check 통과.
- CSS 클래스 검사: 직접 규칙이 없는 토큰 34개에서 33개로 감소. 나머지는 조합 클래스와 기존 표식 등을 포함하며, 개수만으로 스타일 결함을 의미하지 않음.

## 범위와 한계

실행 중인 로컬 개발 사이트에서 확인했다. 운영 사이트 배포는 수행하지 않았다. 관리자 전용 저장 흐름과 모든 대진 진행 상태는 실제 운영 데이터로 실행하지 않았으며, 관리자 영역은 소스와 공유 스타일 및 회귀 테스트로 확인했다. 데이터 서비스, 저장 방식, 경기 결과 계산은 수정하지 않았다. 두 디자인 문서에 남아 있는 과거 표면과 모서리 설명의 차이는 이번 코드 수정과 별도로 남아 있다.
